# Mannat Sidhu, portfolio

Live at https://mannat-sidhu.github.io/portfolio

## Edit the content
Everything on the site lives in `src/data/site.ts`: projects, skills, modules, resume, links.
Edit it (on GitHub you can click the file, then the pencil icon), commit, and the site redeploys in about two minutes.

## Run it locally
```
npm install
npm run dev
```

## Resume PDF
`public/mannat-sidhu-resume.pdf` is printed from the /resume/ page. Replace that file to use a different PDF.
